# DSH Harmony Sender

DSH 电脑端的轻量文字发送插件。手机客户端是本仓库独立的 ArkUI 应用；本包只注册 `/harmony-send` 命令，不包含网页界面或另一个连接服务器。

## 使用

1. 在兼容的 DSH 中通过插件管理器安装本包（公开 Release 中的 `dsh-harmony-sender-0.1.0.tgz`）。本包声明了 `dsh.bundle` 和 `cordis.patch.yml`，需要 Host 提供 `commands` 服务。
2. 在 DSH Desktop 使用已有的“连接手机”生成二维码；在鸿蒙客户端“连接电脑”扫码并完成配对。
3. 在电脑会话中输入 `/harmony-send 这里是要在手机查看的文字`。手机打开同一个会话，即可通过原有历史/实时通道显示和复制这段内容。

这只发送你在命令中指定的文字，不会自动抓取所有回复、隐藏思考或附件；不会触发模型。发送成功表示写入了电脑会话，**不是手机送达或已读回执**。手机离线后重新打开会话，可以从保留的历史读取。每次上限 16 KiB UTF-8。

## 连接与安全

本插件没有开放端口、保管手机凭据、下载隧道、改变防火墙或绕过证书。LAN/HTTPS 公网连接沿用 DSH Desktop 的二维码、PIN、撤销及网络策略。请使用可信 LAN，公网使用 HTTPS。已有 DSH 原生会话仍可完整双向交互；本命令仅提供额外的文字发送功能。

指定文字会进入**原 DSH 会话的持久日志**并由已经获得该会话访问权限的设备读取。删除插件不会删除历史。不要把密码或密钥发进会话。`recordInput:false` 避免命令输入再复制到 command/run，正文仍按设计保存在 command/done 事件中。

## 兼容与验收

依赖官方 `commands.register` 和命令执行器的 `command/run`、`command/done` 持久事件。本仓库对固定官方服务版本进行命令注册/注销及持久事件测试，并验证未改动的上游 Desktop bridge 能转发该事件。完整桌面应用交互和不同版本仍需实测，不能仅凭安装清单声明覆盖所有 DSH 版本。

本项目独立维护，尚未收录官方/社区市场。与 `saya-ch/dsh-mobile` 的 Android/WebView 方案是不同产品；不解析其 dsh1/dsh2 私有 CA 配对，也不复用其凭据。
