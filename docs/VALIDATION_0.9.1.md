# 0.9.1 三项修复与验收

## 状态栏与顶栏重叠

已在虚拟 P90 复现：全屏布局与透明系统栏组合在后台返回后，标题和按钮会进入时间/电量所在区域。一次只按 uitest 坐标判断通过的测试被截图否定，未据此交付。不能仅用控件坐标宣称解决重叠。

最终改为 `setWindowLayoutFullScreen(false)`，由系统安排内容避让；状态栏、底部系统栏与页面使用相同主题底色，保留统一视觉背景。Navigation/NavDestination 显式保留安全区。布局配置只在窗口建立时执行，前台和主题同步只更新颜色。

最终原生验收：系统安全区为 136 px，DSH 会话页、聊天页及后台恢复后按钮顶部均为 164 px。已逐张查看实际截图：时间/电量和应用按钮分开，正文及底部输入区完整。截图同样覆盖初次配对、进入聊天、展开/收起调用与返回前台；不是只检查连接入口。

## 三个相同导出选项

独立聊天、DSH 会话、图像记录使用同一个原生 `Menu` Builder，仅有“长图 PNG / Markdown / PDF”三个等高选项，移除 ActionSheet 大段说明及挤在一起的选项。三个入口均通过原生 UI 检查和截图审阅。导出内容过滤、历史不全标识与系统保存选择器不变。

## 调用默认收起

连续思考、工具和 Agent 调用合并为一行，默认关闭；正常正文与最终答案直接显示。打开分组可见各调用，再点具体调用查看参数/结果；未知工具及错误也可折叠。分组是显示层，未改会话正文或导出来源。

兼容旧嵌套 `tool-result` 和新版 `message.toolCallId / isError / content`；按调用编号跨 step 更新原调用，避免多出“工具”行和已完成调用仍显示运行中。解析字符串 JSON 参数用于摘要；保留错误与详情，未返回完整结果的已结束调用不冒称成功。无编号结果保留独立折叠键。查看详情时暂停自动滚到底部，避免刷新移动用户正在点击的行。

虚构回归包含推理、Agent、未知工具、JSON 字符串参数、跨 step 的工具结果及失败结果。P90 验证默认只出现一行、展开分组、展开终端详情、再次收起和后台恢复，均通过。

## 验证与限制

`npm run check`：103 项通过。官方 ArkTS 编译通过。`tools/verify-three-fixes.mjs` 只操作 `com.szk.dshconnect.qa` 隔离包，并使用虚构数据、固定上游桥接；源码中的测试页不进入生产包。原生截图位于忽略目录，不公开上传。没有读用户会话、调用付费模型或改模型配置。

本轮尚未验收 Mate 90 真机；不将模拟器结果描述为所有系统版本和机型均已解决。SDK 仍有既有 possible-throw 等警告，未宣称 lint 全绿。市场申请和鸿蒙商店提交状态没有改变。
